# Osamah Agent — تطبيق الذكاء الاصطناعي الشخصي للمهندس أسامة العُمري

تطبيق **React Native / Expo** أصلي (Managed Workflow) بواجهة عربية احترافية مصممة لأجهزة Android الحديثة، يتكوّن من وكيل ذكاء اصطناعي عملي يتولّى تنظيم المهام، البحث الموثّق، المحادثة الصوتية، وتصميم الكتب والمستندات والعروض التقديمية بصيغ حقيقية.

> **النواة:** عميل رفيع (Thin Client) يتبع سياسة **Server-First** — لا يتصل بموفّري الـ AI مباشرةً من الجهاز، بل عبر خادم **OSAMAH** (tRPC) الذي يحمل المفاتيح السرية ويقوم بالتوجيه والاستدلال.

---

## ✨ المزايا الرئيسية

- **وكيل أسامة** — عقل مدبّر يتلقّى طلبك، يوجّهه ذكيًّا، يضغط التوكن، يكتب ردًّا مفصّلًا موثّقًا (مضاد للهلوسة) عبر خادم OSAMAH.
- **محادثة صوتية كاملة** — إدخال صوتي عبر الميكروفون (تسجيل على الخادم) مع نطق الردود (TTS) بطابَق عربي سليم.
- **مولّد PDF الحقيقي** — يمرّ بمراحل: استقبال الطلب → تفكير/جمع المحتوى → ترتيب/تنظيم → تنسيق → إنشاء ملف PDF فعلي على القرص.
- **صانع العروض التقديمية** — عروض من 5 إلى 120+ شريحة تُخزَّن في قاعدة البيانات المحلية.
- **مخطط الحياة / الخرائط الذهنية** — أدوات عملية لتحقيق الأهداف وتنظيم الأفكار.
- **المتصفح الذكي** — قراءة المقالات وتلخيص المحتوى الصافي وإدارته.
- **البحث المعمّق** — تجميع المصادر الموثّقة المتوافقة من الخادم.
- **الواجهة** — عربية RTL، متجاوبة، آمنة من حواف الشاشة (Safe Areas/Insets)، تلتزم بعادات وأدوات Android الحديثة.

## 🧱 البنية التقنية

| الطبقة | التقنية |
| --- | --- |
| الإطار | Expo SDK **57** + React Native 0.86 + React 19 |
| اللغة | TypeScript (~6.0) |
| إدارة الحالة | Zustand |
| الخادم الخلفي | عميل tRPC (`@trpc/client` + `httpBatchLink` + `superjson`) |
| قاعدة البيانات المحلية | expo-sqlite |
| الصوت | expo-audio (تشغيل/تسجيل) + expo-speech (TTS) |
| توليد PDF | pdf-lib + arabic-reshaper + خطوط Noto Sans Arabic |
| التصفح | react-native-webview |
| الشكل | react-native-safe-area-context + reanimated + gesture-handler |

## 🚀 التشغيل

### المتطلبات

- Node.js ≥ 20
- Android Studio / جهاز Android (مع **Expo Go** أو مشروع مبني)
- حساب على خادم OSAMAH للاتصال الكامل

### التثبيت والتشغيل

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تجهيز متغيرات البيئة (نموذج آمن)
cp .env.example .env
# ثم عدّل EXPO_PUBLIC_API_BASE_URL ليشير إلى خادم OSAMAH

# 3) تشغيل التطبيق
npm start          # Expo dev server على المنفذ 8081
npm run android    # تشغيل على جهاز Android
```

### الفحص

```bash
npm run typecheck   # tsc --noEmit
```

## ⚠️ الأمان والسياسة

- **لا تُحمَّل المفاتيح السرية في التطبيق** — كل المفاتيح والتوكنات تبقى على خادم OSAMAH ويصل إليها التطبيق عبر الوسيطة (Middleware) الآمنة.
- `.env` (الأسرار الحقيقية) **مستثنى** من Git (راجع `.gitignore`).
- التطبيق يشمل الوصول إلى الميكروفون لتسجيل الأوامر الصوتية ويوضّح ذلك في طلب الإذن.

## 🧪 حالة المشروع

- الكود يُبنى ويُفحص بنجاح (`tsc --noEmit` = 0 أخطاء).
- صُمّم للعمل على Android الحديث مع دعم RTL وSafe Areas ولوحة المفاتيح.
- البنية الخلفية (Server-First) تجعل الربط مع OSAMAH مستقرًّا وشبيهًا بالمرجع الأصلي على مستوى السلك (wire-compatible).
