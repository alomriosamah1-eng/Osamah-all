# Osamah-all Integration Workspace

يحتوي هذا المجلد على تطبيق React Native/Expo المحدث داخل `react-native-app`، ونسخ المصدر المفحوصة للمستودعات المساندة داخل `external-repositories`. مشروع الجذر الأصلي هو Android/Kotlin، لذلك لم يتم استبداله أو خلط ملفاته مع Expo.

المستودعات غير المتاحة CV-Maker وMindMap مستبعدة بناءً على توجيه المستخدم، ولا توجد نسخة أو ادعاء بتحميلها.

ملفات `PROVENANCE.txt` داخل كل مجلد تثبت الرابط والفرع والـcommit الذي تم فحصه عند التجميع.
